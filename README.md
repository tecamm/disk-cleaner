# 🧹 Disk Cleaner

Мощная и безопасная утилита для очистки дискового пространства и поиска тяжелых файлов, написанная на Python. 

Проект разработан с упором на стабильность работы с большими объемами данных и безопасность операционной системы.

## 🚀 Ключевые возможности

* **Асинхронное сканирование:** Интерфейс не зависает при обработке десятков тысяч файлов благодаря многопоточности и лимитированию отрисовки UI.
* **Умные фильтры:** Поиск по размеру, возрасту (в днях) и конкретным расширениям.
* **Точный поиск дубликатов:** Сравнение файлов происходит не по названиям, а по криптографическому хэшу (SHA-256).
* **Системный щит:** Встроенная защита от удаления системных директорий Windows (`Windows`, `Program Files`, `ProgramData`), даже если программа запущена от имени Администратора.
* **Экспорт отчетов:** Выгрузка результатов сканирования в форматах `.txt` и `.csv`.

## 🛠 Технологический стек
* **Язык:** Python 3
* **GUI:** CustomTkinter
* **Хэширование:** hashlib (SHA-256)
* **Сборка:** auto-py-to-exe (PyInstaller)
